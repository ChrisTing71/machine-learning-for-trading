# 第 1 章導讀:流程就是你的優勢

整理日期:2026-10-06

## 這一章到底在講什麼

這一章只有一個主張:在交易裡,長期能賺錢靠的不是挑到最厲害的模型,而是有一套有紀律的研究流程。

理由是市場會變。今天有效的規律,明年可能就失效。模型再複雜,只要它假設「未來和過去一樣」,遲早會壞掉。所以作者把機器學習交易重新定義成一個「適應問題」,而不是「選模型比賽」。

整章其實在回答三個問題:

- 市場會怎麼變?(1.1 給你一組詞彙)
- 那研究該怎麼做才不會騙到自己?(1.2、1.3、1.5 講流程)
- 「市場狀態」這個概念實際上能拿來做什麼?(1.4 加上兩本筆記本)

這份導讀是根據資料夾裡的 README 和兩本筆記本整理的,不是根據書的內文。1.1、1.2、1.3、1.5 沒有對應的程式碼,所以那幾節只能講到 README 摘要的深度。

## 先搞懂的幾個詞

這五個詞都在描述「市場變了」,差別在於變的是什麼、以及你什麼時候知道。下面是一般的白話定義,書中的用法可能更細。

| 名詞 | 白話意思 | 例子 |
| --- | --- | --- |
| 結構性斷裂 (structural break) | 規則永久改變,回不去了 | 交易制度改革、匯率制度改變 |
| 市場狀態 (regime) | 一段行為穩定的時期,之後可能再回來 | 平靜期與恐慌期輪流出現 |
| 資料漂移 (data drift) | 模型的輸入長得不一樣了 | 波動度整體變高、成交量結構改變 |
| 概念漂移 (concept drift) | 輸入和結果之間的關係變了 | 同樣的訊號,以前預示上漲,現在不再有效 |
| 線上偵測 (online detection) | 資料一筆筆進來時,即時判斷是否變了 | 實盤監控發出警報 |

最容易混淆的是斷裂和狀態。斷裂是「換了一個世界」。狀態是「同一個世界的不同天氣」,會反覆出現。兩本筆記本處理的都是後者。

## 各節重點

### 1.1 為什麼流程紀律很重要

靜態的模型會在變動的市場裡慢慢失效。近年的衝擊事件讓很多「以為不會變」的假設現出原形。所以重點不是找到一個永遠有效的模型,而是有能力發現它失效、並且跟著調整。

### 1.2 ML4T 工作流程

這是全書的骨架:一條從研究到上線的流水線,實盤的結果再回頭餵給研究。其中有兩個觀念最值得記住。

- **時點正確的資料**:回測時只能用「當時真的看得到」的資料。用了事後修訂的數字,就是偷看未來。
- **探索與確認的界線**:探索階段可以儘量試。但要記錄試過幾次,並留一份從沒碰過的資料做最後驗證。試了一百次只報最好的那次,結果不可信。

流程圖(依 README 的描述畫的,書中的圖可能分得更細):

```
          ┌──────────── 回饋迴路:監控發現的問題回到研究 ────────────┐
          ▼                                                          │
     界定範圍  →  特徵與模型  →  策略設計  →   部署    →    監控 ─────┘
   (明確的規則)   (反覆迭代)    (貼近現實)  (有紀律地上線) (上線後持續進行)
   ─────────────────────────────────────────────────────────────────
                    地基:時點正確的資料基礎建設
```

### 1.3 因果推論與生成式 AI

兩者都是放進流程裡的工具,不是流程的替代品。因果推論幫你問「這個訊號為什麼有效」,而不只是「它有沒有效」。生成式 AI 讓你能處理文字這類非結構化資料,但也帶來資訊洩漏、幻覺和流程膨脹的新風險。結論是工具越強,紀律越重要。

### 1.4 跟上變化的市場狀態

這是唯一有程式碼的一節。核心立場是:市場狀態主要是一面看風險的鏡子,不是可靠的進出場訊號。它的用途是辨認「現在處在不利的環境」,然後執行事先訂好的風險動作。兩本筆記本就是在示範這件事,也示範它的極限。

### 1.5 個人與機構的工作流程

機構有內建的審查和關卡,有人會擋住你。個人研究者沒有,所以要自己建立:寫文件、設檢查點、事先訂好「什麼情況就停手」。個人的優勢是靈活,而且可重複使用的工具會讓研究品質越累積越好。

## 筆記本一:factor_regimes

這本筆記本用因子報酬把過去一百年的每個月分成兩種狀態,結論是這個標籤適合拿來理解歷史,不適合拿來交易。

它的步驟如下。

1. **載入資料**。AQR 的九個月報酬序列:四個跨資產策略(價值、動能、利差、防禦)、兩個美股策略、三個資產類別本身。可用的完整月份是 1,190 個月,從 1927 年到 2026 年。
2. **清理與標準化**。缺資料的月份直接丟掉,不填補。每個序列縮放到相同尺度,避免波動大的序列主導結果。
3. **試不同的群數**。分別用 2 到 6 群去配適高斯混合模型,再用三個指標比較:BIC、AIC、輪廓係數。
4. **選定兩群**。三個指標意見不一。AIC 想要更多群,但多出來的群月份太少、標籤跳來跳去。作者選兩群,因為這樣的狀態才描述得出來。
5. **為兩群命名**。模型只給編號 0 和 1。作者看哪一群的股票平均報酬高,就叫它「風險偏好」,另一群叫「風險趨避」。
6. **驗證標籤有沒有意義**。對照歷史事件、比較兩種狀態的波動度、看每個因子在兩種狀態各賺多少。
7. **檢查狀態能維持多久**。答案是很短,一年會換好幾次。

### 得到的結論

- 利差和防禦策略平時看起來像安全的收益,情況轉壞時卻正好停止賺錢。價值和債券相反,反而賺更多。
- 所以只看一個策略的長期平均報酬不夠。要分狀態看,才知道它在你最需要的時候靠不靠得住。
- 標籤變動太頻繁,照著它調整部位會被交易成本吃掉。
- 標籤是用整段歷史算出來的,每個月的標籤都「看過」它之後的資料。這是描述,不是預測。

### 一個容易漏看的陷阱

筆記本算了「風險趨避狀態的最大回撤」,數字很大。但那是把所有風險趨避的月份抽出來、頭尾相接後算的。中間的復甦月份被拿掉了,好幾個年代的下跌被接成一段。沒有任何人真的經歷過那個回撤。

教訓是:平均數可以分狀態算,因為它不在乎順序。回撤這種要看路徑的統計量,路徑一被切開就變成另一個東西,必須說清楚是怎麼算的。

## 筆記本二:macro_regimes

這本筆記本改用總體經濟指標來分狀態,再拿股市資料來檢驗,結論是檢驗只通過一半,而且分群結果不太穩定。

好處是分群時完全沒看市場資料。所以事後拿股市表現來對照,是一個真正獨立的檢驗。

它的步驟如下。

1. **選四個指標**。失業率、聯邦基金利率、十年期減兩年期殖利率利差、消費者物價指數。每一個代表一件說得出口的事。
2. **轉成月資料**。每個月取最後一筆,並確保較晚的資料不會混進較早的月份。
3. **物價指數改用年增率**。物價指數幾乎每個月都在漲。直接用原始數字分群,只會分出「早期」和「晚期」。
4. **分成四群**。資料是 276 個月,從 2003 年到 2025 年。四群這個數字是沿用 Two Sigma 的研究,不是算出來的。
5. **用手寫規則命名**。這次配適得到的名稱和月數見下表。
6. **拿 S&P 500 來檢驗**。比較每種狀態的波動度和最大回撤。
7. **擾動測試**。換一個隨機起點、或少用幾個月的資料重新跑,看結果會不會變。
8. **對照實驗**。把檔案裡 25 個序列全丟進去,看會不會更好。

| 狀態名稱 | 月數 |
| --- | --- |
| 復甦 (Recovery) | 100 |
| 緊縮 (Tightening) | 72 |
| 通膨 (Inflation) | 53 |
| 擴張 (Expansion) | 51 |

### 檢驗的結果

- **通過的一半**:波動度的排序合乎經濟直覺。緊縮期的市場平靜,物價或失業率異常的狀態波動大。
- **沒通過的一半**:最深的回撤落在「危機餘波」那個狀態。高失業率加零利率,是央行在崩盤之後才造成的。所以標籤是跟著崩盤一起到,不是提前到。
- **不穩定**:換個起點或少三個月資料,分群就會變到連狀態名稱都不同。作者的態度是把這個結果一起公布,不要只挑好看的那次。

### 對照實驗的教訓

把 25 個序列全丟進去,分離度分數反而比較高。但那個模型只是把時間照順序切成四塊,從不回頭。

| 模型 | 群數 | 區段數 | 重新回到的群 |
| --- | --- | --- | --- |
| 核心,4 個序列 | 4 | 8 | 3 |
| 擴充,25 個序列 | 4 | 4 | 0 |

核心模型會回到舊的狀態,所以它能說 2008 年和 2020 年之後是同一種情況。擴充模型做不到,因為裡面塞了一堆只會一路往上的序列(GDP、物價、就業人數),還有很多幾乎重複的殖利率。

分數高不代表分得有意義,資料多也不代表資訊多。

## 容易卡住的觀念

筆記本裡的統計名詞很密,下面每個只講「它在回答什麼問題」。

| 名詞 | 它在回答什麼 | 怎麼讀 |
| --- | --- | --- |
| 分群 (clustering) | 哪些月份彼此長得像? | 沒有標準答案,模型自己找群組 |
| 高斯混合模型 (GMM) | 假設資料來自幾個鐘形分配,每個月最可能來自哪一個? | 給每個月一個群編號和機率 |
| K-means | 每個月離哪個中心點最近? | 比 GMM 簡單,拿來當對照 |
| 標準化 | 怎麼讓不同尺度的序列公平比較? | 減平均、除標準差 |
| BIC、AIC | 多加一群值不值得? | 越低越好;BIC 對多加群罰得比較重 |
| 輪廓係數 (silhouette) | 各群之間分得開嗎? | -1 到 1,越高越開;不代表有意義 |
| 區段 (episode) | 同一個標籤連續維持了多久? | 區段短代表標籤一直跳 |
| 最大回撤 (max drawdown) | 從高點最多跌了多少? | 跟順序有關,不能隨便切開來算 |
| 調整蘭德指數 (ARI) | 兩次分群的結果有多一致? | 0 等於隨機,1 等於完全相同 |
| 主成分分析 (PCA) | 這一堆序列裡其實有幾個獨立的方向? | 前幾個成分佔比高,代表資料很重複 |
| 樹狀圖與 Ward 連結法 | 哪些指標帶的是同樣的資訊? | 越早合併的越相似 |
| 共表相關係數 (cophenetic) | 這棵樹忠實反映原本的距離嗎? | 接近 1 代表忠實 |
| 前推式配適 (walk-forward) | 只用當時已知的資料,結果會怎樣? | 標籤要能拿來交易就必須這樣做,第 6 章才教 |
| 隱藏式馬可夫模型 (HMM) | 如果狀態傾向延續,每個月最可能在哪個狀態? | 補上 GMM 缺的時間觀念,第 9 章才用 |

有一個觀念貫穿兩本筆記本:GMM 沒有時間概念。它把每個月當成互不相關的點,不知道上個月是什麼狀態。所以標籤容易跳來跳去。

## 讀完該帶走什麼

兩本筆記本的模型都很普通,四行程式碼就能配適。作者真正想教的是配適之後的檢查,以及結果不好看時仍然如實報告。這就是章名「流程就是你的優勢」的意思。

- 市場狀態標籤是看風險的鏡子,不是買賣訊號。
- 群數、狀態名稱、起始日期都是人做的選擇,要說明選了什麼、為什麼。
- 用全部歷史算出來的東西只能描述過去,不能拿來預測。
- 統計量要說清楚是怎麼算的,同一個數字可能有兩種意思。
- 分數高不等於有意義,要用模型沒看過的東西來驗證。
- 下結論前先微調設定重跑一次,看結論還在不在。
